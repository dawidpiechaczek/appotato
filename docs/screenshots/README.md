# Screenshots

The main README links to four files in this directory. Until they exist the images render broken,
so drop them in with exactly these names:

| file | what to capture |
|---|---|
| `pantry.png` | the pantry with a handful of items across categories, at least one expired (red badge) and one expiring soon (amber) so all three badge colours are visible |
| `add-item.png` | the add sheet open, name and quantity filled in, a category chip selected |
| `scanner.png` | the scanner tab with the camera running — a real barcode in frame, not the permission screen |
| `dark.png` | the pantry again with the system in dark mode, for the side-by-side |

The paywall is deliberately not here: on `NoOpBilling` it only ever renders the retry state, so a
screenshot of it would show a broken-looking screen. Add one once billing is wired to a real store.

Portrait, one device, same device for all four. Around 1080px wide is plenty — the README scales
them down anyway, and anything larger just makes the repository heavier to clone.
